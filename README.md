# Sentiment-Analysis-on-text-data-using-NLTK
# 🎬 Movie Review Sentiment Analysis using NLTK

A Machine Learning project that classifies movie reviews as **Positive** or **Negative** using the Naive Bayes algorithm from NLTK.

---

## 📌 Project Overview

This project uses the **NLTK Movie Reviews dataset** to build a sentiment classifier.  
The model is trained using:

- Text preprocessing
- Stopword removal
- Feature extraction (Top 2000 frequent words)
- Naive Bayes classification

The final model achieves approximately **78% – 85% accuracy**.

---

## 📂 Dataset

Dataset used:
- NLTK built-in `movie_reviews` corpus
- 2000 labeled movie reviews
  - 1000 Positive
  - 1000 Negative

---

## 🛠️ Technologies Used

- Python
- NLTK
- Naive Bayes Classifier
- Frequency Distribution
- Natural Language Processing (NLP)
